# Инструкция: установка Ubuntu Server и развёртывание Kaspersky Security Center

Репозиторий содержит готовую инструкцию по развёртыванию **Kaspersky Security Center Linux 15.2**
на **Ubuntu Server 24.04 LTS** с СУБД **MariaDB 10.11** и **Kaspersky Security Center Web Console 15.2**
в двух форматах, а также исходники, из которых собираются оба файла.

## Готовые документы

| Файл | Описание |
| --- | --- |
| `docs/Инструкция_Ubuntu_Server_и_Kaspersky_Security_Center.pdf` | PDF, 33 страницы, A4, с обложкой, оглавлением с номерами страниц, закладками и 8 иллюстрациями |
| `docs/Инструкция_Ubuntu_Server_и_Kaspersky_Security_Center.docx` | DOCX (Word), A4, с обложкой, автособираемым оглавлением, колонтитулами и нумерацией страниц |

Содержание документов идентично: это один и тот же текст и одни и те же иллюстрации, собранные из общего источника.

## Что внутри инструкции

1. Общие сведения: назначение, термины, состав ПО, схемы развёртывания (варианты А и Б), требования, порты, чек-лист подготовки.
2. Подготовка: таблица параметров стенда для заполнения, параметры ВМ, загрузка дистрибутивов.
3. Установка Ubuntu Server 24.04 LTS: экраны установщика Subiquity по шагам, разметка диска, сеть, SSH;
   первичная настройка ОС — обновление, время, FQDN, netplan, swap 1,5 × ОЗУ, отключение автоперезагрузки, ufw, локаль.
4. Установка и настройка MariaDB: версия не ниже 10.11.10, `mariadb-secure-installation`, файл `99-ksc.cnf`
   с рекомендованными производителем параметрами, лимиты файловых дескрипторов, создание БД `kav` и учётной записи `KSCAdmin`.
5. Установка Kaspersky Security Center Linux: служебная учётная запись `ksc` и группа `kladmins`, лимиты `nofile`,
   установка пакета `ksc64`, пошаговая таблица ответов `postinstall.pl`, проверка четырёх служб и портов,
   тихая установка с файлом ответов, размещение файлов.
6. Установка Web Console: файл ответов `/etc/ksc-web-console-setup.json`, установка пакета, проверка служб,
   первый вход, базовые настройки сервера, замена самоподписанного сертификата.
7. Первичная настройка KSC: учётные записи, активация лицензии, инсталляционные пакеты Агента,
   подключение устройств, политики и задачи, проверка работоспособности.
8. Обслуживание: резервное копирование БД и `klbackup`, восстановление, обновление KSC и Web Console,
   регламент обслуживания, журналы.
9. Диагностика типовых неисправностей (включая ошибку `table_open_cache`), сбор данных для поддержки.
10. Чек-лист приёмки из 16 пунктов.

Приложения: порты, значения по умолчанию и пути, полный пример файла ответов, полезные команды, ссылки на документацию.

## Структура репозитория

```
assets/                 схемы развёртывания (PNG, генерируются скриптом)
build/
  meta.py               метаданные документа, параметры стенда, соглашения
  content_1..4.py       текст инструкции в виде блоков (единый источник для обоих форматов)
  textutil.py           разбор встроенной разметки (`код`, **жирный**, ссылки)
  draw_schemes.py       генерация схем развёртывания (Pillow)
  draw_figures.py       генерация остальных иллюстраций: маршрут, порты, экраны, диск, резервные копии
  render_pdf.py         сборка PDF (reportlab)
  render_docx.py        сборка DOCX (python-docx)
docs/                   готовые PDF и DOCX
```

## Пересборка документов

Требуется Python 3.10+ и пакеты:

```bash
pip install reportlab python-docx pillow
```

Затем:

```bash
python3 build/draw_schemes.py    # при необходимости перерисовать схемы
python3 build/draw_figures.py    # перерисовать остальные иллюстрации
python3 build/render_pdf.py      # -> docs/*.pdf
python3 build/render_docx.py     # -> docs/*.docx
```

Шрифты для PDF берутся из системного каталога `/usr/share/fonts/truetype/dejavu`
(DejaVu Sans, DejaVu Sans Mono) — они обеспечивают корректную кириллицу.

## Правка содержания

Текст хранится в `build/content_*.py` в виде списка блоков:

```python
B(("h1", "4. Установка и настройка СУБД MariaDB"))
B(("p", "Текст с `командой` и **выделением**."))
B(("code", ["apt -y install mariadb-server"]))
B(("table", {"head": [...], "rows": [[...]], "widths": [...], "caption": "..."}))
B(("note", "Примечание")), B(("warn", "Предупреждение"))
```

Поддерживаются блоки: `h1`, `h2`, `h3`, `p`, `ul`, `ol`, `code`, `table`, `checklist`,
`params_table`, `note`, `warn`, `figure`, `pagebreak`. После правки достаточно пересобрать оба файла —
PDF и DOCX останутся согласованными.
