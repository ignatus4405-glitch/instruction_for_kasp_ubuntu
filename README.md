# Инструкция: установка Ubuntu Server и развёртывание Kaspersky Security Center

Репозиторий содержит готовую инструкцию по развёртыванию **Kaspersky Security Center Linux 17**
на **Ubuntu Server 26.10** с СУБД **MariaDB 11.8** и **Kaspersky Security Center Web Console 17**
в двух форматах, а также исходники, из которых собираются оба файла.

> Ubuntu Server 26.10 — промежуточный (interim) выпуск с поддержкой до июля 2027 года; в официальном
> перечне поддерживаемых ОС KSC 17 указаны Ubuntu 22.04, 24.04 и 26.04 LTS. Для продуктивной
> эксплуатации за пределами этого срока используйте 26.04 LTS — порядок действий в инструкции тот же.

## Что внутри инструкции

1. Общие сведения: назначение, термины, состав ПО, схема развёртывания (все компоненты на одной ВМ),
   требования, порты, чек-лист подготовки.
1.8. Клавиши и приёмы работы для начинающих: таблица клавиш (`Tab`, `Space`, `Enter`, `Ctrl+O`…),
   копирование и вставка команд, работа в редакторе `nano`, многострочные блоки `cat > файл <<'EOF'`.
2. Подготовка: таблица параметров стенда для заполнения, параметры ВМ, загрузка дистрибутивов.
3. Установка Ubuntu Server 26.10 по экранам: для каждого экрана Subiquity указано, какие клавиши
   нажимать (`Tab`, `↑`/`↓`, `Space`, `Enter`) и что должно получиться; разметка диска (с отдельным
   `/boot` вне LVM — требование установщика 26.10), сеть, SSH, первый вход в систему;
   первичная настройка ОС — обновление, время, FQDN, netplan, swap 1,5 × ОЗУ, отключение автоперезагрузки, ufw, локаль.
4. Установка и настройка MariaDB 11.8: `mariadb-secure-installation`, файлы `99-ksc-bind.cnf` и `99-ksc.cnf`
   с рекомендованными производителем параметрами, лимиты файловых дескрипторов, создание двух баз
   (`kav` для Сервера администрирования и `iamdb` для службы IAM) и двух учётных записей (`KSCAdmin`, `KSCIAM`).
5. Установка Kaspersky Security Center Linux 17: служебные учётные записи `ksc` и `ksciam`, группа `kladmins`,
   лимиты `nofile`, установка пакета `ksc64`, пошаговая таблица ответов `postinstall.pl` (24 пункта,
   включая параметры службы IAM), проверка пяти служб и портов, тихая установка с файлом ответов,
   размещение файлов, разбор ошибок `postinstall.pl` по кодам СУБД (в том числе `1227` — привилегия
   `SET USER`) и чистый повтор установки.
6. Установка Web Console 17: файл ответов `/etc/ksc-web-console-setup.json` с блоком `trusted`
   (порты IAM 4444/9050 и OpenAPI 13299), установка пакета, проверка пяти служб, первый вход,
   базовые настройки сервера, замена самоподписанного сертификата.
7. Первичная настройка KSC: учётные записи, активация лицензии, инсталляционные пакеты Агента,
   подключение устройств, политики и задачи, проверка работоспособности.
8. Обслуживание: резервное копирование БД и `klbackup`, восстановление, обновление KSC и Web Console,
   регламент обслуживания, журналы.
9. Диагностика типовых неисправностей (службы `kladminserver_srv` и `kliam_srv`, ошибка `table_open_cache`,
   недоступность Web Console, ошибка DNS `DNS_PROBE_FINISHED_NXDOMAIN` при открытии консоли, файл `hosts`
   на рабочем месте), сбор данных для поддержки.
10. Чек-лист приёмки из 16 пунктов.

Приложения: порты, значения по умолчанию и пути, полный пример файла ответов, полезные команды, ссылки на документацию.

## Структура репозитория

```
assets/                 иллюстрации (PNG, генерируются скриптами из build/)
build/
  meta.py               метаданные документа, параметры стенда, соглашения
  content_1..4.py       текст инструкции в виде блоков (единый источник для обоих форматов)
  textutil.py           разбор встроенной разметки (`код`, **жирный**, ссылки)
  draw_schemes.py       генерация схемы развёртывания (Pillow)
  draw_figures.py       генерация остальных иллюстраций: маршрут, порты, экраны, диск, резервные копии
  render_pdf.py         сборка PDF (reportlab)
  render_docx.py        сборка DOCX (python-docx)
docs/                   готовые PDF и DOCX
```

## Пересборка документов

Требуется Python 3.10+ и пакеты:

```bash
pip install reportlab python-docx pillow pymupdf
```

Затем:

```bash
python3 build/draw_schemes.py    # при необходимости перерисовать схемы
python3 build/draw_figures.py    # перерисовать остальные иллюстрации
python3 build/render_pdf.py      # -> docs/*.pdf (и кликабельное оглавление, нужен pymupdf)
python3 build/render_docx.py     # -> docs/*.docx
```

Шрифты для PDF берутся из системного каталога `/usr/share/fonts/truetype/dejavu`
(DejaVu Sans, DejaVu Sans Mono) — они обеспечивают корректную кириллицу.

## Правка содержания

Текст хранится в `build/content_*.py` в виде списка блоков:

```python
B(("h1", "4. Установка и настройка СУБД MariaDB"))
B(("p", "Текст с `командой` и **выделением**."))
B(("code", ["apt -y install mariadb-server"]))
B(("table", {"head": [...], "rows": [[...]], "widths": [...], "caption": "..."}))
B(("note", "Примечание")), B(("warn", "Предупреждение"))
```

Поддерживаются блоки: `h1`, `h2`, `h3`, `p`, `ul`, `ol`, `code`, `table`, `checklist`,
`params_table`, `note`, `warn`, `figure`, `pagebreak`. После правки достаточно пересобрать оба файла —
PDF и DOCX останутся согласованными.
